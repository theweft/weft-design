# Brand: logo, colours, type

Status: decided 2026-10-18. Assets and usage rules live in weft-website:
[brand/README.md](https://github.com/theweft/weft-website/blob/main/brand/README.md), generated by
`brand/generate.py` and served at `https://theweft.org/brand/`. This document records the
decisions and why.

## Decisions

| Topic | Decision | Why |
|---|---|---|
| Name | weft (see the naming section of [04-decisions.md](04-decisions.md)) | Kept despite a crowded name; trademark revisited before the first release |
| Logomark | 2×2 plain weave: two vertical warp threads, two horizontal weft threads, square ends, real gaps where a thread goes under, open spacing with stubs | Literal meaning of the name; recognisable at 16 px; the cut-outs make it work on any background and in one colour |
| Colours | Indigo warp and amber weft, separate values for light and dark backgrounds (below) | Liked look, tuned so the two threads differ in brightness: the weave stays visible in greyscale and for colour-blind viewers |
| Wordmark | "weft" in <!--f:brand.font-->Inter<!--/f-->, weight <!--f:brand.font_weight-->600<!--/f-->, converted to outlines | Widely used, SIL Open Font License (permits logos); outlines need no installed font |
| Lockups | Horizontal (mark left, name right) and stacked (mark above) | The two standard arrangements; x-height of the name is 21/48 of the mark |
| Variants | `light`, `dark`, `black`, `white` for every logo | Light and dark backgrounds, plus one-colour use (print, photos, engraving) |
| App icon, avatar | Logomark on the light background, full square | The dark-mode indigo disappears on a navy tile; platforms round the corners themselves |
| Favicon | SVG that follows the browser's light or dark mode | One file, correct colours in both themes |
| Site text | System font stack, no web fonts | Privacy, strict CSP, speed; only the wordmark uses Inter, as outlines |
| Minimum size | Logomark <!--f:brand.mark_min_px-->16<!--/f--> px | Smallest size where the weave still reads |
| Licence | Artwork MIT, like all weft repositories; CC-BY-4.0 considered for future prose and images (see [03-licensing.md](03-licensing.md)) | Free reuse in articles, talks and integrations; the name and logo are protected by trademark, not copyright |

| Weft (horizontal threads) | <!--f:brand.color.weft_light-->#c18215<!--/f--> | <!--f:brand.color.weft_dark-->#f6bb55<!--/f--> |
| Wordmark | <!--f:brand.color.ink_light-->#1d2333<!--/f--> | <!--f:brand.color.ink_dark-->#e6e8ee<!--/f--> |

Measured: brightness contrast between the two threads 2.8 (light) and 3.5 (dark), up from 1.6
and 1.1 with the first draft; every colour at least 3:1 against its background. Links on the
site use separate accent colours, because the dark-mode indigo is too dark for text.

## Rejected alternatives

| Alternative | Why not |
|---|---|
| First draft: thin threads, over and under drawn with background-coloured strokes | Broke on any other background and in one colour |
| 2×2 with rounded, pill-shaped ends | Too close to Slack's logo |
| 3×3 weave, rounded or square-cut | Busy at 16 px; the square-cut tile was the most distinctive alternative |
| 2×2 inside a circle ("swatch") | Distinctive; kept in reserve if the hash-like outline ever becomes a problem |
| 2×2 rotated 45° | The rotational symmetry starts to resemble a swastika |
| 2×2 filling a rounded square | Still read as a hash |
| Ink and madder red; indigo and madder; teal and madder | Better greyscale in places, but less liked (ink/indigo), or poor greyscale (teal) |
| Original indigo and amber values | Both threads turned the same grey |

## Clearance and rights

- **Similarity check (2026-10-18):** compared with the logos of other weft and weave projects
  (WeaveMindAI weft, WeftCut, SourceWeft, Weaveworks, Weave, Heddle) and with Slack, Plaid and
  Hashnode. Nearest relative: Slack (bars in a hash), clearly differentiated by square ends, two
  colours and open spacing. WeaveMindAI's weft also uses blue and orange, as a gradient ribbon;
  accepted.
- **Pending (maintainer):** reverse image search with Google Lens and TinEye, and the image search
  of WIPO's Global Brand Database for registered figurative marks.
- **Copyright:** the mark is simple and AI-assisted, so copyright protection is weak; that limits
  what weft can claim, not what weft may use.
- **Trademark:** protection comes from use as weft's brand and, later, registration (word mark
  first, figurative mark when final). Deferred with the name decision; a trademark policy follows
  when others distribute weft.

## Changing the brand

Edit `brand/generate.py` in weft-website, update the facts here, run `just brand` there and
`just check` here. CI in weft-website fails when generated files are out of date.
